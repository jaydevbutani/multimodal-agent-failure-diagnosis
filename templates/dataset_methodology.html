About the Dataset: Public Agent Benchmark Trajectories

1. Multi-Benchmark Diversity

Derived from rigorous agent execution suites across openhands, swe-bench, sdlc_fix, and org_migration. Captures diverse real-world software engineering failure patterns.

2. Heterogeneous Agent Frameworks

Spans multiple LLM architectures (e.g. claude-sonnet-4-6, claude-haiku-4-5) and frameworks (claude-code, openhands), preventing backbone-specific diagnostic bias.

3. Complete Synthetic Isolation

Curated synthetic demonstration traces (under data/demo_traces/) are strictly quarantined for user interactive UI inspection and viva demonstration. Zero synthetic data was utilized during model training or held-out test evaluation.
