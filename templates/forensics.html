Evidence-Based Root-Cause Reasoning Architecture

Unlike black-box diagnostic tools, the Agent Health Intelligence platform generates evidence-grounded root-cause attributions. Predictions are substantiated through three complementary layers: cross-modal attention gating, SHAP predictive feature importance, and Who&When responsible component localization.

hub

1. Cross-Modal Fusion Gating

Dynamically balances tabular execution telemetry with sequential tool trajectory embeddings:

g = σ(W_g · [h_tab ; h_seq] + b_g)
h_fused = g ⊙ h_tab + (1 - g) ⊙ h_seq
logit = W_out · ReLU(W_dense · h_fused)

When an agent's failure manifests through repetitive commands, the sequence gate weight expands to capture transition anomalies.

Tool Execution Exception Downstream API timeout, missing environment package, or permission error.
