Derived Behavioral Telemetry Formulas

To capture silent agent failure modes, the system computes 10 domain-specific behavioral features from raw execution telemetry. These features quantify retry looping, excessive searching, code churn, and tool command entropy without requiring source-code ground truth.

DERIVED_error_rate bug_report
error_count / max(1, tool_calls_total)

Normalizes total logged environment errors against execution span length. High values indicate repetitive tool execution faults.

Range: [0.0, 1.0]
DERIVED_retry_ratio replay
retry_count / max(1, error_count)

Identifies cyclic command retry thrashing where the agent repeatedly re-executes failing shell commands without changing arguments.

Range: [0.0, 1.0]
DERIVED_search_to_edit_ratio manage_search
search_tool_calls / max(1, edit_tool_calls)

Detects information over-exploration deadlocks where the agent burns token budgets on grep/find queries without editing files.

Range: [0.0, ∞]
DERIVED_edit_churn edit_note
patch_size_lines / max(1, unique_files_edited)

Measures modification density per file. Abnormally high churn (> 300 lines) flags unbounded code rewrites.

Unit: lines/file
DERIVED_tool_entropy shuffle
− Σ (p_i × log(p_i))

Shannon entropy of the sequential tool vocabulary. Low values (< 0.50) signify monotonic looping of the same tool command.

Unit: nats
DERIVED_tool_intensity speed
tool_calls_total / max(1, total_turns)

Tool execution frequency per conversational turn. Distinguishes multi-call workflows from single-shot actions.

Unit: calls/turn
