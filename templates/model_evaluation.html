Agent Diagnostics & SWE-bench Execution Corpora
Dataset Source Agent Diagnostics & SWE-bench

Multi-agent software engineering trials spanning diverse LLM backbones (Claude Sonnet 4.6, Claude Haiku 4.5) and frameworks (OpenHands, Claude-Code).

Total Trials & Partitions 11,995 Verified Trials

Strict partition split: 7,999 train (66.7%), 2,000 validation (16.7%), and 1,996 held-out test (16.6%).

Target Variable & Class Balance passed (0 = Fail, 1 = Pass)

Overall distribution: 76.9% passed (9,224 trials) vs 23.1% failed (2,771 trials). Imbalance ratio: 3.34:1 mitigated via loss reweighting.

Zero-Leakage Strategy GroupShuffleSplit by task_id

Guarantees 0% task overlap across splits. Models are strictly tested on entirely unseen problem repositories to prevent test contamination.

Feature Engineering & Telemetry Extraction

Domain-specific behavioral features are extracted from execution telemetry and tool-call patterns before model inference. These include error rates, command retry ratios, search-to-edit ratios, edit churn density, tool invocation intensity, and Shannon entropy over tool-call sequences.

Section 4 — Results & Scientific Interpretation

Empirical Trade-Off Analysis
star Best Overall Balance: XGBoost (Macro-F1: 0.7659)

XGBoost provides the strongest overall classification balance across both passed and failed agent sessions. Its gradient-boosted decision trees effectively capture non-linear thresholds in derived ratios such as retry ratio and edit churn, yielding the highest PR-AUC (0.7132).

verified Best Failure Sensitivity: Multi-View Fusion (Recall: 72.95%)

The Proposed Multi-View Fusion model is more sensitive to detecting failed agent executions. In mission-critical production observability, false negatives (missing an autonomous agent failure) are far costlier than false positives. Fusing trajectory sequence tokens with telemetry catches subtle multi-turn loops.
